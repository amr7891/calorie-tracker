# Workout Log

A personal bodybuilding log: weekly schedule, routines with sets × reps targets, per-set logging with a rest timer, cardio, body weight, and weekly volume goals per muscle.

Single-page web app (`index.html`), no build step. Data is stored in the browser on the device you use it on (localStorage). Use **Progress → Backup** to copy your data and **Restore** to move it to another device.

Hosted with GitHub Pages from the `main` branch.
